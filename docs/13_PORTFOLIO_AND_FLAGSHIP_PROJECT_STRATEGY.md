# 13 --- Portfolio and Flagship Project Strategy

## Portfolio thesis

The portfolio must demonstrate production engineering, not a collection
of notebooks.

## Flagship Project 1 --- AI Career OS

Demonstrates: - data ingestion - data modeling - NLP/LLM structured
extraction - taxonomy/knowledge graph thinking - analytics -
recommendation logic - evaluation - FastAPI - PostgreSQL - Next.js -
Docker - AWS - CI/CD - observability - security - product reasoning

Required hiring artifacts: - architecture diagram - ADRs - data
lineage - eval report - test report - live deployment - cost report -
security notes - README - 3-minute English architecture explanation -
15-minute interview defense

## Flagship Project 2 --- Production RAG System

Requirements: - ingestion - chunking experiment - embeddings -
hybrid/vector retrieval - reranking - citations - retrieval metrics -
generation metrics - prompt-injection tests - FastAPI - Docker - cloud
deployment - tracing/observability - latency/cost analysis

## Flagship Project 3 --- Classical/Deep ML Production System

Requirements: - real dataset - baseline - leakage controls - feature
pipeline - experiment tracking - model comparison - error analysis - API
serving - monitoring/drift concept - CI/CD - deployment

## Advanced experiment --- Fine-tuning/QLoRA

Not presented as "trained an LLM" unless evaluation demonstrates
improvement. Must document: - why fine-tune - base model choice - data -
LoRA/QLoRA decision - hardware/VRAM - hyperparameters - before/after
evaluation - inference cost - limitations

## Evidence standard

Every portfolio project answers: 1. What business/technical problem? 2.
Why this architecture? 3. What alternatives were rejected? 4. How was
success measured? 5. What failed? 6. What did you change? 7. How does it
behave in production? 8. What are cost/security/reliability trade-offs?
